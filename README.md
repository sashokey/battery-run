Estimates how long a MacBook will run on its current charge and from a full charge, based on the average rate of the current discharge session. Requires macOS 27 on Apple silicon and an internal battery.

## Installation

Download the app ZIP from [Releases](https://github.com/sashokey/battery-run/releases), unzip it, and move `Battery Run.app` to Applications. The app is ad-hoc signed and is not notarized.

## Usage notes

An estimate appears after at least one percentage point and one minute of discharge. The rate includes time spent asleep. Historical start times are approximate; when no earlier reading is available, monitoring starts when the app opens.
